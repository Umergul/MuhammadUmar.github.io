# Personal Portfolio Website

My portfolio site, live at https://umergul.github.io/MuhammadUmar.github.io/ via GitHub Pages.

## Stack

- HTML5 / CSS3 / JavaScript (no build step, no backend)
- Bootstrap, on a Colorlib template base

## Preview locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Deployment

Pushes to `main` go live automatically through GitHub Pages.

## Structure

| Path | Contents |
|---|---|
| `index.html` | Main single-page site |
| `css/` `js/` `lib/` | Styles, scripts, vendor libraries |
| `images/` `fonts/` | Assets |
| `scss/` | Source styles |

## Note

Template base by Colorlib; page content is being updated to match current positioning (AI Automation / ML).
